# C3OS 🖥️

> Custom lightweight OS for embedded devices (ESP32 / RP2040 / etc.)

![License](https://img.shields.io/badge/license-MIT-green)
![PlatformIO](https://img.shields.io/badge/platform-PlatformIO-blue)

---

## 🚀 Features
- Lightweight OS kernel written in C/C++  
- Framebuffer graphics support (800x600x16)  
- Audio initialization & testing  
- Multi-tasking basics implemented  
- Embedded-friendly (ESP32 / microcontrollers)
